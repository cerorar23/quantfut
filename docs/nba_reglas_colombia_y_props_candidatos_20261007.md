Sus notas conservan el canal de observación manual del DOM; no se presentan como bytes HTTP originales. Sportium se conserva como texto HTML devuelto por ZenRows MCP, con extracción y hashes; el MCP no proporcionó estado HTTP ni URL final verificados. País, mercado y condiciones se acreditan mediante el documento observado, no por la mera configuración del proxy. Las fechas de licencia de los footers tampoco son fechas de vigencia de las reglas.

El historial público de `bets_today.csv` registra commits de 2026-02-12. Es una pista adicional de publicación, no un timestamp del proveedor ni una prueba independiente de recepción original. No se inventó hora a partir de la fecha de partido ni se mezclaron las 77 filas con las 27.151 candidatas anteriores. **Cero parejas nuevas aceptadas:** las 243.132 estrictas siguen intactas. GitHub produjo 26 GET en total y 19 blobs verificados mediante SHA-1 Git y SHA-256; los árboles completos quedaron fijados, pero la lectura de archivos fue acotada, no una auditoría exhaustiva de todo el código o historial.

ZenRows realizó **diez solicitudes de scraping**: seis iniciales y cuatro seguimientos justificados por enlaces oficiales o páginas vacías. Reserva conservadora nueva: **250 créditos**; cota acumulada **2.232/3.200**, dejando 968 de margen autorizado. Las lecturas gratuitas de uso pasaron de 1.674 a 1.804 créditos de cuenta, incremento observado de 130. No se atribuye como coste exacto exclusivo de estas llamadas: los saltos del contador no permiten reconciliar cada petición, y un salto de 35 activó la parada de nuevas solicitudes. Se preservan las lecturas y la reserva completa. Sin compras ni llamadas nuevas a The Odds API.

Validación: 48 corridas, 19.636 evidencias y cadena previa de 97 eventos verificados; ocho controles negativos rechazan mezcla de países, reescritura de perfiles, liquidación automática, push de equipo aplicado a jugador, mínimo de participación inventado, recepción retrofechada, promoción de cuarentena y ampliación de presupuesto. Arnés antes/después: **768 aprobadas, diez omitidas**; Docker no disponible para su comprobación. Archivos de producción NBA y gates preservados. Dos fallos locales iniciales —selección del contador de uso y dependencia de parser ausente— se corrigieron antes de sus respectivas operaciones; se usó el parser estándar instalado.

Catálogo nuevo: `apps/nba/.local/normalized/nba_pending49_catalog_20261007/rules_catalog.json`; revisiones separadas de los perfiles anteriores. Verificación y checkpoint: `apps/nba/.local/normalized/nba_pending49_validation_20261007/`. Capturas reales del 8 de octubre UTC corresponden todavía al 7 de octubre de Ciudad de México.
