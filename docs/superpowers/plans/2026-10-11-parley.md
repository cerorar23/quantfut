# Parley del día — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pestaña pública "Parley" con 1-5 parlays diarios de cuota 1,90-5,00 (uno por escalón), el más probable de cada escalón, sellados en la cadena antes de los partidos y con historial prometido frente a real.

**Architecture:** Igual que la escalera: reglas puras en `publish/parley.py` (filtro de patas, mochila sobre ln(cuota), liquidación, control), base de datos en `publish/parley_datos.py` (candidatas desde `escalera_datos.opciones`, elegir, liquidar, informe), enganches en `daily.run` antes de `seal()`, `hashchain._collect` y `clv.settle_pending`; ruta `GET /parley` y vista `parley` en `frontend/app.js`.

**Tech Stack:** Python 3.12, Postgres (psycopg), FastAPI, pandas/numpy (control), JavaScript sin framework + `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-11-parley-design.md`

## Global Constraints

- Escalones: 1 = 1,90-2,20 · 2 = 2,20-2,70 · 3 = 2,70-3,40 · 4 = 3,40-4,30 · 5 = 4,30-5,00 (`lo <= cuota < hi`; el 5 incluye 5,00).
- Patas por parlay: mínimo 2, máximo 6. Cuota mínima por pata 1,15.
- Una pata por partido; un partido en un solo parlay del día.
- Solo probabilidad: sin filtro de valor. Fuera solo la cuota errónea: `prob · cuota − 1 > 0,25`.
- Ventana: partidos de `now + 15 min` a `now + 24 h`, ligas activas, cuotas de ≤ 6 h (`escalera.MAX_EDAD_PRECIO`).
- Sin doble oportunidad (ningún proveedor la cotiza). Mercados = `escalera.MERCADOS`.
- Orden del job: predecir → picks → alta → escalera → **parley** → `seal()`. No se reordena nada existente.
- Tablas inmutables con `deny_mutation()`. No se deshabilita ningún trigger.
- `PARLEY_ENABLED` apagado por defecto; `LOTE_PARLEY_DESDE = None` hasta el despliegue.
- Textos al usuario en español. Tests: `PYTHONPATH=src .venv/Scripts/python -m pytest` (Windows) y `cd frontend && npm run check`.
- Finales de línea: escribir con `newline="\n"`; no normalizar archivos ajenos (memoria del proyecto).

## Review Focus

1. Día con pocos partidos (0, 1 o 2 con cuota): no debe romper el job; devuelve 0 o 1 parlay y `estado` claro.
2. Partido aplazado dentro de un parlay: la pata queda nula (×1,00) y el ticket se liquida con el resto; no se queda pendiente para siempre.
3. Cuota errónea de una casa (WH 19,00 frente a ~5): no puede colarse en un parlay.
4. Job re-ejecutado el mismo día (cron dos veces o a mano): no duplica tickets ni rompe el UNIQUE.
5. Combinación justo en el borde de un escalón (p. ej. 2,20 exacto): cae en un solo escalón, nunca en dos ni fuera.

Cada línea tiene su test en la tarea dueña: (1) Tarea 2 `test_dia_con_pocos_partidos` y Tarea 3 `test_sin_partidos_no_rompe`; (2) Tarea 3 `test_aplazado_deja_la_pata_nula_y_liquida_el_ticket`; (3) Tarea 2 `test_cuota_erronea_fuera`; (4) Tarea 3 `test_no_elige_dos_veces_el_mismo_dia`; (5) Tarea 2 `test_bordes_de_escalon`.

```sql
    ticket_id    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dia          DATE NOT NULL,
    escalon      SMALLINT NOT NULL CHECK (escalon BETWEEN 1 AND 5),

    n_patas      SMALLINT NOT NULL CHECK (n_patas BETWEEN 2 AND 6),

    UNIQUE (dia, escalon)
);

CREATE TABLE IF NOT EXISTS parley_patas (

                                                 'corners_away')),

    line         REAL,
```

```python
    por = {}
```

```python
# src/qf/publish/parley.py
"""
Parley del día (pedido del usuario, 2026-10-11).

Cada día, 1 a 5 parlays de cuota total 1,90-5,00: uno por ESCALÓN de cuota y,
en cada escalón, la combinación MÁS PROBABLE de todos los mercados que ya
calcula la escalera. Decisiones del usuario: escalones de cuota; un partido en
un solo parlay del día; solo probabilidad, sin filtro de valor.

LO QUE NO PROMETE: elegir por probabilidad sube el acierto, no el valor. El
margen de la casa se paga en CADA pata y se multiplica: a la larga los
parlays pierden aunque acierten lo prometido. El historial lo enseña entero.

Probabilidad del parlay = producto de sus patas (partidos distintos). Un sesgo
pequeño por pata se multiplica; por eso el control por escalón (`control`)
pausa el escalón que acierte por debajo de lo prometido.

Este módulo es la parte pura. La base de datos está en `parley_datos.py`.
"""
from __future__ import annotations

import math
from datetime import datetime

from ..eval.soft_vs_sharp import MIN_WEEKS, _weekly_ci
from . import alta_prob as ap
from .escalera import MERCADOS, Opcion

ESCALONES: tuple[tuple[int, float, float], ...] = (
    (1, 1.90, 2.20), (2, 2.20, 2.70), (3, 2.70, 3.40), (4, 3.40, 4.30), (5, 4.30, 5.00))
CUOTA_MIN_PATA = 1.15
# Valor esperado por encima del cual la cuota se da por error de la casa
# (11-oct: William Hill pagaba a Deportivo a 19,00 con el mercado en ~5).
EV_ERRONEA = 0.25
MIN_PATAS, MAX_PATAS = 2, 6
# Rejilla de la búsqueda: ancho de celda en ln(cuota) y combinaciones por celda.
_CELDA = 0.002
_POR_CELDA = 2


def en_escalon(cuota: float, escalon: int) -> bool:
    _, lo, hi = ESCALONES[escalon - 1]
    ultimo = escalon == ESCALONES[-1][0]
    return lo <= cuota and (cuota < hi or (ultimo and cuota <= hi))


def filtrar(opciones: list[Opcion], now: datetime) -> list[Opcion]:
    """Patas que pueden entrar: mercado conocido, cuota ≥ 1,15, sin cuota errónea, sin fuga."""
    return [o for o in opciones
            if o.cand.market in MERCADOS and o.price >= CUOTA_MIN_PATA
            and o.ev <= EV_ERRONEA
            and (o.odds_as_of is None or o.odds_as_of <= now)]


def _frente(patas: list[Opcion]) -> list[Opcion]:
    """Quita las dominadas: otra pata del mismo partido con prob y cuota ≥."""
    out, mejor_cuota = [], 0.0
    for o in sorted(patas, key=lambda o: (-o.cand.prob, -o.price)):
        if o.price > mejor_cuota:
            out.append(o)
            mejor_cuota = o.price
    return out


def _meter(estados: dict, clave: tuple[int, int], e: tuple) -> None:
    lista = estados.setdefault(clave, [])
    lista.append(e)
    lista.sort(key=lambda x: -x[0])
    del lista[_POR_CELDA:]


def _clave_orden(sel: tuple[Opcion, ...]) -> tuple:
    """Más probable; luego menos patas; luego match_id ascendente."""
    return (-round(math.prod(o.cand.prob for o in sel), 12), len(sel),
            sorted(o.match_id for o in sel))


def buscar(patas: list[Opcion], escalon: int) -> tuple[Opcion, ...] | None:
    """
    La combinación más probable del escalón: como mucho una pata por partido,
    de MIN_PATAS a MAX_PATAS patas. Mochila de elección múltiple sobre
    ln(cuota): cada celda (patas, ln cuota) guarda sus `_POR_CELDA` mejores
    combinaciones con la suma exacta, y al final se verifica la cuota exacta.
    """
    por_partido: dict[str, list[Opcion]] = {}
    for o in patas:
        por_partido.setdefault(o.match_id, []).append(o)
    _, lo, hi = ESCALONES[escalon - 1]
    techo = math.log(hi) + 1e-12
    estados: dict[tuple[int, int], list[tuple]] = {(0, 0): [(0.0, 0.0, ())]}
    for mid in sorted(por_partido):
        opciones = _frente(por_partido[mid])
        nuevos = {k: list(v) for k, v in estados.items()}
        for (k, _), lista in estados.items():
            if k == MAX_PATAS:
                continue
            for lp, s, sel in lista:
                for o in opciones:
                    s2 = s + math.log(o.price)
                    if s2 > techo:
                        continue
                    _meter(nuevos, (k + 1, int(s2 // _CELDA)),
                           (lp + math.log(o.cand.prob), s2, sel + (o,)))
        estados = nuevos
    finales = [sel for (k, _), lista in estados.items() if k >= MIN_PATAS
               for _, _, sel in lista
               if en_escalon(math.prod(o.price for o in sel), escalon)]
    return min(finales, key=_clave_orden) if finales else None


def armar_dia(patas: list[Opcion], pausados: set[int] | frozenset = frozenset()
              ) -> list[tuple[int, tuple[Opcion, ...]]]:
    """Del escalón más bajo al más alto, sin repetir partido; el que no sale se salta."""
    usados: set[str] = set()
    out = []
    for escalon, _, _ in ESCALONES:
        if escalon in pausados:
            continue
        sel = buscar([o for o in patas if o.match_id not in usados], escalon)
        if sel is None:
            continue
        out.append((escalon, sel))
        usados |= {o.match_id for o in sel}
    return out


def liquidar(patas: list[tuple[str | None, float, float]]) -> dict | None:
    """(outcome, cuota, prob) de cada pata → resultado del ticket, o None si falta alguna."""
    if any(outcome is None for outcome, _, _ in patas):
        return None
    factor = 1.0
    for outcome, price, _ in patas:
        factor *= price if outcome == "win" else 0.0 if outcome == "loss" else 1.0
    outcomes = {outcome for outcome, _, _ in patas}
    res = "perdido" if "loss" in outcomes else "ganado" if "win" in outcomes else "nulo"
    return {"outcome": res, "factor_pago": round(factor, 4),
            "prob_efectiva": math.prod(p for o, _, p in patas if o in ("win", "loss"))}


def _contados(liquidados: list[dict]) -> list[dict]:
    """Los nulos no cuentan; 'ganado' es el acierto."""
    return [{**r, "outcome": "win" if r["outcome"] == "ganado" else "loss"}
            for r in liquidados if r["outcome"] != "nulo"]


def control(liquidados: list[dict]) -> dict:
    """
    ¿Promete de más algún escalón? Mismo criterio que la alta probabilidad
    (`alta_prob.control`): con n ≥ MIN_N_CONTROL, fallo grosero (z ≤ Z_GROSERO)
    pausa ya; con ≥ MIN_SEMANAS_CONTROL semanas, IC99 de (acertado − prometido)
    entero bajo cero pausa. `liquidados`: escalon, prob (efectiva), outcome, kickoff_utc.
    """
    filas = _contados(liquidados)
    if not filas:
        return {"pausados": [], "motivos": ["Sin parlays liquidados todavía"]}
    f = ap._marco(filas)
    pausados, motivos = [], []
    for escalon, g in f.groupby("escalon"):
        nombre = f"escalón {int(escalon)}"
        if len(g) < ap.MIN_N_CONTROL:
            motivos.append(f"{nombre}: muestra insuficiente ({len(g)} < {ap.MIN_N_CONTROL})")
            continue
        z = ap._z(g)
        if z <= ap.Z_GROSERO:
            pausados.append(int(escalon))
            motivos.append(f"{nombre}: acierto real muy por debajo del prometido "
                           f"(z {z:.1f}, {len(g)} parlays)")
            continue
        if g["week"].nunique() < ap.MIN_SEMANAS_CONTROL:
            motivos.append(f"{nombre}: muestra insuficiente "
                           f"(menos de {ap.MIN_SEMANAS_CONTROL} semanas)")
            continue
        ic = _weekly_ci(g["diff"].to_numpy(float), g["week"].to_numpy(),
                        level=ap.NIVEL_IC_CONTROL)
        if ic is None:
            motivos.append(f"{nombre}: muestra insuficiente (menos de {MIN_WEEKS} semanas)")
            continue
        if ic[1] < 0:
            pausados.append(int(escalon))
            motivos.append(f"{nombre}: acierto real por debajo del prometido "
                           f"(IC99 {ic[0] * 100:+.1f} a {ic[1] * 100:+.1f} puntos)")
    return {"pausados": sorted(pausados), "motivos": motivos}


def _bloque(filas: list[dict]) -> dict:
    n = len(filas)
    if not n:
        return {"n": 0, "aciertos": 0, "prob_media": None, "acierto_real": None,
                "unidades": 0.0, "roi": None}
    aciertos = sum(1 for r in filas if r["outcome"] == "ganado")
    unidades = sum(float(r["factor_pago"]) - 1.0 for r in filas)
    return {"n": n, "aciertos": aciertos,
            "prob_media": round(sum(float(r["prob"]) for r in filas) / n * 100, 1),
            "acierto_real": round(aciertos / n * 100, 1),
            "unidades": round(unidades, 2), "roi": round(unidades / n * 100, 1)}


def resumen(liquidados: list[dict]) -> dict:
    """A 1 unidad por parlay; sin nulos."""
    filas = [r for r in liquidados if r["outcome"] != "nulo"]
    escalones = sorted({int(r["escalon"]) for r in filas})
    return {"total": _bloque(filas),
            "por_escalon": {str(e): _bloque([r for r in filas if int(r["escalon"]) == e])
                            for e in escalones}}
```

```python
Base de datos del parley del día: elegir, liquidar e informar. Las reglas
están en `parley.py`.

ORDEN: `daily.run()` llama a `select_and_persist()` justo ANTES de `seal()` y
`hashchain._collect` mete en el lote los tickets y patas decididos ese día. Un
ticket solo se enseña si su lote existe y se selló DESPUÉS de decidirlo: lo
que no está en un lote sellado no existe.

from __future__ import annotations

import argparse
import json
import logging
from datetime import datetime, timedelta, timezone

from ..config import settings
from ..db import execute, query, query_one
from . import alta_prob_datos as ad
from . import escalera_datos as ed
from . import hashchain
from . import parley as pl
from . import picks as pk

log = logging.getLogger(__name__)

# El "día" del parley: de la decisión (08:00 UTC) a 24 h después, que cubre la
# jornada americana entera (02:00-02:00 en México).
VENTANA = timedelta(hours=24)


def _sql_sellado() -> str:
    """Mismo criterio que `escalera_datos._sql_sellado`, con la fecha del parley."""
    desde = hashchain.LOTE_PARLEY_DESDE
    corte = (f"AND b.batch_date >= DATE '{desde.isoformat()}'"
             if desde is not None else "AND FALSE")
    return f"""JOIN prediction_batches b
             ON b.batch_date = (t.decided_at AT TIME ZONE 'UTC')::date
            AND t.decided_at <= b.created_at
            {corte}"""


def _partidos(now: datetime) -> list[dict]:
    return query(
        """SELECT m.match_id, m.kickoff_utc, m.league_id, m.home_team_id, m.away_team_id,
                  m.referee
           FROM matches m JOIN leagues l ON l.league_id = m.league_id
           WHERE m.status = 'scheduled' AND l.active
             AND m.kickoff_utc BETWEEN %s AND %s
           ORDER BY m.kickoff_utc""",
        (now + pk.MIN_LEAD, now + VENTANA))


def candidatas(now: datetime) -> tuple[list, int]:
    """Patas que pueden entrar y cuántos partidos no tenían precio."""
    rho = ad._rho_activo()
    modelos = ed.Modelos(now)
    todas, sin_precio = [], 0
    for m in _partidos(now):
        res = ed.opciones(m, now, rho, modelos)
        if res is None:
            sin_precio += 1
            continue
        todas.extend(res)
    return pl.filtrar(todas, now), sin_precio

    """Tickets liquidados y sellados, con la hora del primer partido (semana del control)."""
    return query(

                   (SELECT min(m.kickoff_utc) FROM parley_patas p
                    JOIN matches m ON m.match_id = p.match_id
                    WHERE p.ticket_id = t.ticket_id) AS kickoff_utc
            FROM parley_tickets t
            JOIN parley_resultados r ON r.ticket_id = t.ticket_id
            {_sql_sellado()}""")

def select_and_persist(now: datetime | None = None, dry_run: bool = False) -> dict:
    now = now or datetime.now(timezone.utc)
    dia = now.astimezone(timezone.utc).date()
    if not settings.parley_enabled and not dry_run:
        return {"estado": "desactivado"}
    if not dry_run and not hashchain.lote_lleva_parley(dia):
        return {"estado": "sin_corte",
                "motivo": "LOTE_PARLEY_DESDE no fijada o posterior a hoy: no se elige nada"}
    if not dry_run and ad._lote_sellado(dia):
        return {"estado": "lote_sellado", "motivo": "Lote del día ya sellado: no se elige nada"}
    if not dry_run and query_one("SELECT 1 AS x FROM parley_tickets WHERE dia = %s", (dia,)):
        return {"estado": "ya_elegido", "dia": dia.isoformat()}

    patas, sin_precio = candidatas(now)
    ctl = pl.control(_liquidados())
    plan = pl.armar_dia(patas, set(ctl["pausados"]))
    out = {"estado": "elegido" if plan else "sin_combinacion", "dia": dia.isoformat(),
           "candidatas": len(patas), "partidos": len({o.match_id for o in patas}),
           "sin_precio": sin_precio, "pausados": ctl["pausados"],
           "tickets": [_ticket_json(e, sel) for e, sel in plan]}
    if dry_run:
        return out

    for (escalon, sel), t in zip(plan, out["tickets"]):
        ticket_id = query_one(
            """INSERT INTO parley_tickets (dia, escalon, cuota_total, prob_total, n_patas)
               VALUES (%s, %s, %s, %s, %s) RETURNING ticket_id""",
            (dia, escalon, t["cuota_total"], t["prob_total"], t["n_patas"]))["ticket_id"]
        for o in sel:
            execute(
                """INSERT INTO parley_patas (ticket_id, match_id, market, selection, line, prob,
                                             fair_price, price, book, odds_source, odds_as_of)
                   VALUES (%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s)""",
                (ticket_id, o.match_id, o.cand.market, o.cand.selection, o.cand.line,
                 round(o.cand.prob, 6), round(1.0 / o.cand.prob, 4), o.price, o.book,
                 o.odds_source, o.odds_as_of))
    log.info("Parley: %s", {k: v for k, v in out.items() if k != "tickets"})
    return out


def settle_pending(now: datetime | None = None) -> dict:
    """Liquida las patas con resultado y después los tickets con todas sus patas liquidadas."""
    now = now or datetime.now(timezone.utc)
    rows = query(
        """SELECT p.pata_id, p.market, p.selection, p.line, m.status, m.kickoff_utc,
                  m.home_goals, m.away_goals, m.home_corners, m.away_corners,
                  m.home_yellow, m.away_yellow, m.home_red, m.away_red
           FROM parley_patas p
           JOIN matches m ON m.match_id = p.match_id
           LEFT JOIN parley_resultados_pata r ON r.pata_id = p.pata_id
           WHERE r.pata_id IS NULL
             AND ((m.status = 'finished' AND m.home_goals IS NOT NULL)
                  OR (m.status = 'postponed' AND m.kickoff_utc < %s))""",
        (now - ed.MARGEN_APLAZADO,))
    n_patas = 0
    for r in rows:
        res = ed.resultado(r, now)
        if res is None:
            continue
        n_patas += execute(
            """INSERT INTO parley_resultados_pata (pata_id, outcome, home_goals, away_goals, valor)
               VALUES (%s,%s,%s,%s,%s) ON CONFLICT (pata_id) DO NOTHING""",
            (r["pata_id"], *res)) or 0

    pendientes = query(
        """SELECT t.ticket_id, p.price, p.prob, rp.outcome
           FROM parley_tickets t
           JOIN parley_patas p ON p.ticket_id = t.ticket_id
           LEFT JOIN parley_resultados_pata rp ON rp.pata_id = p.pata_id
           LEFT JOIN parley_resultados r ON r.ticket_id = t.ticket_id
           WHERE r.ticket_id IS NULL
           ORDER BY t.ticket_id""")
    por_ticket: dict = {}
    for f in pendientes:
        por_ticket.setdefault(f["ticket_id"], []).append(
            (f["outcome"], float(f["price"]), float(f["prob"])))
    n_tickets = 0
    for ticket_id, patas in por_ticket.items():
        liq = pl.liquidar(patas)
        if liq is None:
            continue
        n_tickets += execute(
            """INSERT INTO parley_resultados (ticket_id, outcome, factor_pago, prob_efectiva)
               VALUES (%s,%s,%s,%s) ON CONFLICT (ticket_id) DO NOTHING""",
            (ticket_id, liq["outcome"], liq["factor_pago"], liq["prob_efectiva"])) or 0
    return {"patas": n_patas, "tickets": n_tickets}
```
