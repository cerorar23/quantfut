Cómo se calculan

Las probabilidades salen de un modelo estadístico propio. La metodología explica qué mide, qué no mide y cuánto ha acertado. Incluso con un 80 % de probabilidad, uno de cada cinco partidos sale al revés: ninguna cifra de esta página es una garantía.
