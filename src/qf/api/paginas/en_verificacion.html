Verify now in your browser (Web Crypto SHA-256)

When you click the button, your browser fetches the public /chain?limit=365 JSON, restores chronological order and recomputes sha256(prev_sha256 + payload_sha256) locally without sending data outside your device.

    Exact sealing formula

    1. The genesis block is a 64-zero hexadecimal string: {{ genesis[:16] }}….
    2. Each new batch takes its canonical JSON fingerprint payload_sha256 (UTF-8 lowercase hex) and concatenates it immediately after the previous link: chain_sha256 = sha256(prev_sha256 + payload_sha256).
    3. The database blocks updates or deletions on sealed rows, while calibration and the public record (in Spanish) let readers inspect outcomes afterwards.

    Zero-dependency terminal check

    If you prefer auditing the chain outside the browser with pure Python 3 standard library (no third-party packages required), run the bundled script:

    python3 scripts/verificar_cadena_publica.py --url https://pronosticosdeportivos.pro/chain?limit=365

    It also supports --archivo chain.json or --dir ./receipts-dir to validate *.receipt.json files and revealed payloads.
