Comprobar ahora en tu navegador (Web Crypto SHA-256)

Al pulsar el botón, tu navegador descarga el JSON público de /chain?limit=365, invierte el orden a cronológico y recalcula localmente sha256(prev_sha256 + payload_sha256) sin enviar datos fuera de tu dispositivo.

    Fórmula exacta del sellado

    1. El bloque de génesis es una cadena hexadecimal de 64 ceros: {{ genesis[:16] }}….
    2. Cada lote nuevo toma su huella JSON canónica payload_sha256 (UTF-8 en hexadecimal minúsculas) y la concatena sin separadores detrás del eslabón anterior: chain_sha256 = sha256(prev_sha256 + payload_sha256).
    3. La base de datos impide modificar o borrar filas ya selladas, y los resultados se auditan después en el historial y en calibración.

    Auditoría sin dependencias desde terminal

    Si prefieres comprobar la cadena fuera del navegador con biblioteca estándar pura de Python 3 (sin instalar librerías externas), utiliza el script incluido en el proyecto:

    python3 scripts/verificar_cadena_publica.py --url https://pronosticosdeportivos.pro/chain?limit=365

    También admite --archivo chain.json o --dir ./ruta-recibos para validar archivos *.receipt.json y lotes revelados.
