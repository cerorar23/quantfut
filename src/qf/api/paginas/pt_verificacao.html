Conferir agora no navegador (Web Crypto SHA-256)

Ao clicar no botão, seu navegador baixa o JSON público de /chain?limit=365, coloca em ordem cronológica e recalcula localmente sha256(prev_sha256 + payload_sha256) sem enviar dados fora do dispositivo.

    Fórmula exata do selo

    1. O bloco gênesis é uma sequência hexadecimal de 64 zeros: {{ genesis[:16] }}….
    2. Cada novo lote usa sua impressão digital JSON canônica payload_sha256 (UTF-8 em minúsculas) concatenada diretamente após o elo anterior: chain_sha256 = sha256(prev_sha256 + payload_sha256).
    3. O banco de dados impede alterar ou apagar registros já selados, e os desfechos podem ser consultados depois em calibração e no histórico público (em espanhol).

    Auditoria sem dependências pelo terminal

    Se preferir auditar a cadeia fora do navegador usando apenas a biblioteca padrão do Python 3 (sem instalar pacotes externos), utilize o script incluído no projeto:

    python3 scripts/verificar_cadena_publica.py --url https://pronosticosdeportivos.pro/chain?limit=365

    Também aceita --archivo chain.json ou --dir ./pasta-recibos para conferir arquivos *.receipt.json e lotes revelados.
