Como são calculadas

As probabilidades vêm de um modelo estatístico próprio. A metodologia explica o que ele mede, o que não mede e quanto já acertou. Mesmo com 80 % de probabilidade, uma em cada cinco partidas sai ao contrário: nenhum número desta página é uma garantia.
